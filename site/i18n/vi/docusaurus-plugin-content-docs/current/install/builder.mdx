## Mỗi công tắc thành gì

| Bạn chọn | Installer nhận |
| --- | --- |
| Coin | `--algo rx/wow` — Monero không thêm gì, vì pool chuyển thuật toán có thể đổi rig sang đồng khác |
| Ví | `--wallet <address>` |
| Tên rig | `--rig-id <name>` |
| Pool | `--pool <host:port>` hoặc `--pool tls://<host:port>` |
| Pool dự phòng | `--failover <host:port>,<host:port>` |
| Ép engine | `--engine zmrig` hoặc `--engine xmrig` (không đặt = tự động) |
| Ép profile | `--profile free` hoặc `--profile watt` (không đặt = tự động) |
| Mạng chỉ mở 443 | `--cloudflare --ws-path <path>` |
| Proxy | `--proxy <url>` |
| Tên pool bị lọc DNS | `--connect-to <host:port>` |
| Host chặn ghi MSR | `--no-msr` |
| Hash thuê | `--nicehash` |
| Không tinh chỉnh host | `--no-tune` |
| Không dò thread | `--no-autotune` |
| Giữ config | *(không có `--force`)* |

Hai quy tắc đáng biết vì chúng đổi cả lệnh, không chỉ thêm một cờ:

- Chọn WebSocket hoặc proxy sẽ ép `--engine zmrig`. Engine C++ không có client
  WebSocket và không hỗ trợ proxy, nên phương án còn lại là một config không gì
  chạy được.
- Pool TLS trở thành một phần của giá trị `--pool` (`tls://host:port`), vì đó là
  dạng mà `oneclick.sh` phân tích.

Địa chỉ bạn gõ được kiểm tra trước khi nút sao chép mở: với Monero là 95 ký tự,
106 cho integrated, chỉ dùng bảng chữ base58. Với sáu đồng còn lại, kiểm tra là
bảng chữ và độ dài hợp lý, kèm cảnh báo khi prefix không phải cái trang này biết —
nó không giả vờ xác minh checksum mà nó không tính. Host pool được kiểm tra dạng
`host:port`, và URL đầy đủ `stratum+tcp://…` dán từ trang nhà cung cấp vẫn được
chấp nhận.

Đồng coin quyết định hai việc. Nó ghim thuật toán (`--algo rx/wow` và tương tự) —
trừ Monero, vì thêm cờ đó sẽ chặn pool chuyển thuật toán đổi rig sang đồng
RandomX trả tốt nhất. Và nó quyết định có preset pool hay không: bảy preset đều là
pool Monero, nên mọi đồng khác sẽ hỏi endpoint thay vì bịa ra một cái. Chi tiết và lệnh mẫu nằm ở [Các coin khác](/docs/pools/coins).

Ô proxy nhận cả URL — `socks5://host:port` hoặc `http://user:pass@host:port` —
vì đó là thứ miner phân tích. Địa chỉ dial chỉ là `host:port`; nó thay IP đã
phân giải nhưng giữ hostname của pool trong SNI và header `Host`, và đó chính là
mục đích: một tên bị resolver nội bộ chặn vẫn dùng được nếu bạn biết nó ở đâu.

## Xem trước đã

Nút xem trước sao chép đúng lệnh đó với `plan` thay cho `install`. `plan` phân
giải pool, engine, profile, chiến lược huge page và kế hoạch autotune, in ra rồi
dừng. Nó không ghi gì cả.

Không lệnh nào chứa bí mật nào của ví: địa chỉ công khai là thứ duy nhất liên
quan, và pool thấy nó là chuyện đương nhiên.
